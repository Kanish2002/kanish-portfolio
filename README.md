# Kanish S — Java Backend Engineer

Personal engineering portfolio for Kanish S, focused on low-latency trading systems, banking, payments, and distributed event-driven architecture.

## Built with

- SvelteKit and TypeScript
- Tailwind CSS
- Static generation for fast, portable deployment

## Run locally

```sh
npm install
npm run dev
```

## Verify and build

```sh
npm run check
npm run build
```

The production site is generated in `build/`.
